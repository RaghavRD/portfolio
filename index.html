RAG evaluation · Test infrastructure

BharatRAG - Fast Test Suite

PR Open

BharatRAG is an open-source RAG evaluation library for Indian languages (Hindi, Marathi, Tamil, Bengali and more). Its tests loaded real SentenceTransformer models from HuggingFace on every run, so they were slow and failed without network access.

Reported the issue (#14) and split model-dependent tests into an integration pytest marker, so the default suite runs fast without downloading models. Updated the GitHub Actions CI to run fast tests on every push and integration tests on main, and documented the workflow in CONTRIBUTING.md. Reported Issue #9 to make the benchmark runner language-agnostic; it has since been resolved upstream.

LibTrack AI — Dependency Release Tracker

Tracks every library a team depends on, flags security issues, and predicts upcoming releases before they ship.

Live Demo GitHub
01 · Problem

Teams usually discover dependency updates and vulnerabilities too late, during a failing build or a security audit. Checking PyPI, npm and GitHub by hand for every project doesn't scale.

02 · Architecture
Vercel CronDjango endpointRegistry fetchOSV security scanOpenAI analysisBrevo email

Service-layer design (LibrarySync → VersionFetch → FutureUpdate → Notification) on Django with PostgreSQL (Supabase).

03 · AI part

When an official registry API fails, Serper web search + the OpenAI API extract the correct version from the web. The LLM also analyzes release cadence and public signals to predict future releases with a confidence score, and teams only get alerts above their chosen threshold.

04 · Result

82libraries tracked
174security alerts surfaced

BuildLedger — Construction Money Manager

One place for contractors and site teams to track budgets, expenses, payments and receipts across construction projects.

Live Demo GitHub
01 · Problem

Construction spending is often tracked in notebooks and chat threads, so owners can't see budget vs. actual spend per site, and partners have no shared, trusted record.

02 · Architecture
Next.js App RouterServer Actions + ZodPrisma ORMPostgreSQL (Supabase)

NextAuth credential login with bcrypt, route middleware, and a Serwist service worker that makes the app installable on mobile.

03 · Key features
Credit / debit ledger across 9 categories (labor, materials, equipment, transport, permits…) with receipts. Team access via invite codes and admin-approved access requests, with admin-only project actions. Per-project budget, total credit and profit summaries, plus CSV export.
04 · Result

Live on Vercel and installable as a PWA, so site teams can log expenses from their phones. Next up: camera receipt capture and offline sync.
